# 播放音源自动切换说明

## 背景

播放器已经完成自定义音源 fallback 优化：当某首歌在当前音源无法播放时，会继续尝试其他可用自定义音源，避免界面显示播放中但实际没有声音。

## 当前状态

该能力已进入稳定使用状态，当前逻辑会在播放 URL 获取失败或当前音源不可用时继续走回退链路，并在全部失败后给出明确错误提示。

## 行为说明

当当前音源无法播放时：

- 按可用音源顺序尝试播放地址。
- 每个音源内部按可用音质策略尝试。
- 成功拿到可播放 URL 后停止继续尝试。
- 全部失败后显示播放失败信息，不再伪装成播放状态。

## 维护建议

后续如果继续调整 fallback 逻辑，需要注意：

- 不打印 Cookie、API Key 等敏感信息。
- 区分“无版权”“URL 获取失败”“URL 可获取但播放失败”等错误类型。
- 保持官方源、网易云 Cookie 请求与自定义网关回退互不污染。
- 修改后至少验证搜索播放、网易云账号歌单播放、每日推荐播放与失败提示。
